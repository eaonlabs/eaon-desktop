# Import logos

Logos for Import from other apps (Settings → ADE and the first-run setup),
each taken from the app itself or its own site or repository, resized to
128px. The marks belong to their owners and are shown only to identify the
app Eaon imports from.

| File | App | Source |
| --- | --- | --- |
| `conductor.png` | Conductor | conductor.build/apple-icon.png |
| `orca.png` | Orca | Orca.app's icon (Contents/Resources/icon.icns) |
| `paradev.png` | Paradev (formerly Superset) | paradev.ai/apple-touch-icon.png |
| `claude-squad.png` | Claude Squad | smtg-ai.github.io/claude-squad/favicon.ico |
| `t3code.png` | T3 Code | T3 Code.app's icon (Contents/Resources/icon.icns) |
| `synara.png` | Synara | Synara.app's icon (Contents/Resources/icon.icns), on a white tile (the mark is black on transparent) |
| `crystal.png` | Crystal | github.com/stravu/crystal, main/assets/icon.png |
| `vscode.png` | Visual Studio Code (its MCP servers) | Visual Studio Code.app's icon (Contents/Resources/Code.icns) |
| `windsurf.svg` | Windsurf (its MCP servers) | windsurf.com/favicon.svg |

Claude, Cursor and Gemini CLI use the tiles already in `../providers` (see its NOTICE.md).
