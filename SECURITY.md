# Security

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/eaonlabs/eaon-desktop/security/advisories/new) of this repository. Don't open a public issue.

Include the Eaon version (Settings → General), the operating system, steps to reproduce, and the impact you expect. We aim to acknowledge reports within 3 business days and to ship a fix for confirmed high or critical issues within 30 days. We'll credit you in the release notes unless you'd rather we didn't.

## Supported versions

Only the latest stable release receives security fixes. Eaon updates itself; managed fleets should deploy new releases promptly.
